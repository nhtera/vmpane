# Contributing to VMPane

Thanks for helping. Before you start:

- Read [docs/development.md](docs/development.md) for setup, scripts and tests.
- Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `chore:` …).
- Keep pull requests small and focused; CI must be green (`scripts/lint.sh`, `scripts/test.sh`).
- Code comments explain *why*; they never reference plan or ticket identifiers.

Security issues: please follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
