# vmpane

VMPane's command-line tool (`VMPane.app/Contents/Helpers/vmpane`; `vmpane install-cli` puts it on the PATH).
Generated by `scripts/gen-cli-docs.sh` from `vmpane --help`.

Exit codes: 0 ok, 1 failed, 64 bad arguments, 66 no such VM, 69 helper or guest agent unavailable,
75 try again (busy, wrong state), 77 refused by the VM's agent policy or the kill switch; `vmpane exec`
exits with the command's own code.

## vmpane

```
OVERVIEW: Control VMPane virtual machines from the command line.

USAGE: vmpane <subcommand>

OPTIONS:
  --version               Show the version.
  -h, --help              Show help information.

SUBCOMMANDS:
  list                    List the VMs in the library.
  info                    Show a VM's settings and state.
  start                   Start a VM (its window shows unless --headless).
  stop                    Shut a VM down (the guest's power button), or turn it
                          off with --force.
  suspend                 Save a VM's memory to disk and stop it; it resumes at
                          the next start.
  pause                   Pause a running VM.
  resume                  Resume a paused VM.
  snapshot                Take, list, restore and delete a VM's snapshots.
  exec                    Run a command in a running VM (needs VMPane's guest
                          tools).
  cp                      Copy a file to or from a running VM: vmpane cp
                          file.txt ubuntu:/tmp/ or vmpane cp ubuntu:/etc/hosts .
  ssh                     ssh into a VM through its port forward to port 22.
  port                    Forward ports from this Mac to a VM.
  screenshot              Save a PNG of a running VM's screen.
  mcp                     Serve VMPane to an AI agent over MCP (stdio), or stop
                          all agents.
  operator                Let your own terminal use of vmpane control VMs
                          whatever their agent policy.
  install-cli             Put vmpane on your PATH (/usr/local/bin, with one
                          administrator prompt; --user: ~/.local/bin).
  doctor                  Check VMPane's installation and running VMs.
  version                 Print VMPane's version.

  See 'vmpane help <subcommand>' for detailed help.
```

## vmpane exec

```
OVERVIEW: Run a command in a running VM (needs VMPane's guest tools).

USAGE: vmpane exec <vm> [--as <as>] [--cwd <cwd>] [--env <env> ...] [--timeout <timeout>] -- [<command> ...]

ARGUMENTS:
  <vm>                    The VM: its name, id or short id.
  <command>               The command and its arguments, after --.

OPTIONS:
  --as <as>               user (the logged-in user) or admin (root / SYSTEM).
                          (default: user)
  --cwd <cwd>             Working directory in the guest.
  --env <env>             An environment variable, NAME=value (repeatable).
  --timeout <timeout>     Kill the command after this many seconds.
  --version               Show the version.
  -h, --help              Show help information.

```

```
OVERVIEW: Forward a port: MAC_PORT:VM_PORT, with /udp for UDP (e.g. 8080:80,
5353:53/udp).

USAGE: vmpane port add <vm> <mapping> [--all-interfaces]

  <vm>                    The VM: its name, id or short id.
  <mapping>               MAC_PORT:VM_PORT[/udp]

OPTIONS:
  --all-interfaces        Listen on every network interface of this Mac, not
```
